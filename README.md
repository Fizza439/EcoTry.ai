# 👗 ECOTRY — AI-Powered Sustainable Virtual Try-On WebApp

**Try before you buy — make more conscious fashion choices.**

## 🌟 About ECOTRY

**ECOTRY** is an AI-powered Virtual Try-On Web Application developed as a Final Year Project at **Government College University Faisalabad (GCUF), 2026**.

The project explores how artificial intelligence can improve online clothing shopping and encourage more conscious purchasing decisions.

ECOTRY allows users to visualize clothing on their own images and receive personalized clothing recommendations before making a purchase.

## ✨ Key Features

### 👗 1. AI Virtual Try-On
- Upload a personal image and a clothing item.
- Visualize how the selected garment looks on the uploaded image.
- Powered by the IDM-VTON pretrained model.

### 📐 2. AI-Based Size Recommendation
- Provides personalized clothing size recommendations.
- Helps users make more informed purchasing decisions.

### 🎨 3. Skin Tone & Style Advisor
- Provides skin-tone-based color recommendations.
- Suggests clothing styles based on body type.
- Helps users explore more suitable clothing choices.

### 🌱 4. Sustainability Awareness
- Provides environmental-impact information about clothing products.
- Includes educational content about fast fashion, textile waste, and sustainable fashion.
- Encourages conscious purchasing through awareness and technology.

## 🚀 How It Works

1. User opens ECOTRY.
2. Uploads a personal image.
3. Selects and uploads a clothing item.
4. AI-powered virtual try-on generates the clothing visualization.
5. The recommendation system provides size, color, and style suggestions.
6. Users explore clothing products and their environmental-impact information.

## 🎯 Problem It Addresses

| Problem | ECOTRY Solution |
|---|---|
| Cannot visualize clothing before purchasing | AI Virtual Try-On |
| Uncertainty about clothing colors | Skin Tone Advisor |
| Difficulty choosing suitable clothing styles | AI Style Recommendation |
| Uncertainty about clothing sizes | AI Size Recommendation |
| Lack of awareness about fashion's environmental impact | Sustainability Awareness |
